# ポイっと LP：セクション構成と画像プロンプト

実装：`/lp`（`src/app/lp/page.tsx`）。画像は `public/lp/` に決まったファイル名で置くと自動で差し替わります（置くまではダッシュ枠のプレースホルダが表示されます）。

---

## 0. 方針：「AIが作った感」を消すために決めたこと

LPが“AIっぽく”見えるのは、だいたい次のせいです。逆をやります。

| よくあるAI感 | ポイっとLPでの扱い |
|---|---|
| 紫〜青のグラデーション、光る球体、回路・脳のモチーフ | 使わない。コーラル1色＋オフホワイトの紙っぽい面だけ |
| 「革命的」「シームレス」「圧倒的」などの空っぽい形容詞 | 使わない。数字と具体物で言う（「1件1分 × 月80件 = 1時間半」） |
| 完全対称の3カラム機能グリッドが延々続く | 機能セクションは1つだけ。前後は非対称レイアウトで崩す |
| 「AI」を主役にした見出し | 主役は結果（かたづく）。AIは手段として2番目に置く |
| 出どころ不明の実績数字・作り話のお客様の声 | 入れない。代わりに「つくった理由」を実話で置く（LP最大の差別化） |
| 何でもできますという万能感 | 「全部を自動にはしません」「最終判断は税理士に」と正直に書く |
| ストック写真の笑顔ビジネスマン | 使わない。人物は最小限、日本の小さな事務局の風景 |

もう1つ大事なこと：**UIを見せるセクションは、AI生成画像ではなく実際のアプリのスクリーンショットを使う**のが一番「本物」に見えます。AI画像はUIの文字が崩れるので、逆効果になります。下の一覧で「実画面」と書いたところは撮影推奨です。

## 2. 画像プロンプト（ChatGPT / GPT Image 用）

### ▼ まず共通スタイル（毎回いちばん上に貼る）

```text
【共通スタイル指定 — 必ず守ってください】
・フラットなベクター風イラスト。輪郭線は、太さがわずかに揺らぐ手描きのペン線。
・使用する色は次の4色と、その薄いトーンのみ。それ以外の色を混ぜない。
  コーラル #E8542B（主役・アクセント） / ミント #1D9E75（うまくいっている合図）
  アンバー #EF9F27（ごく少量） / インク #2C2C2A（線と文字要素）
・背景はオフホワイト #FAF8F5 の無地。パターン・グラデーション背景は不可。
・禁止：グラデーション、光沢、メタリック、ドロップシャドウ、3Dレンダリング、
  ネオン、回路基板、脳、ロボット、ホログラム、星雲、キラキラの多用。
・画像の中に文字・数字・ロゴ・UIラベルを一切描かないこと。書類の文字は線の
  かたまりで表現する。
・余白を広くとる。主要な要素は5つまで。画面いっぱいに詰めない。
・人物を描く場合：顔は目と口を線1本で示す程度。日本の小さな事務所にいる普通の
  服装の人。スーツ姿のステレオタイプなビジネスマンにはしない。
・全体の印象：静かで、実務的で、少しあたたかい。
```

## 3. 実画面スクリーンショット（AI生成しないこと）

`/post`・`/review`・`/months`・`/search` の4画面を、次の条件で撮ってください。

- ブラウザ幅 **1280px**、ズーム100%、ライトモード
- ブラウザのタブ・アドレスバーは写さない（ページ本体のみ）
- デモデータは、取引先名が実在の団体名にならないよう確認する
- 撮ったら `public/lp/shot-post.png` などの名前で保存

スマホ画面（`/post` を375px幅）も1枚あると、セクション08で使えます。

---

## 4. 生成のコツ

1. **1枚ずつ生成する。** 「4枚まとめて」と頼むと、スタイルがバラけます。
2. **共通スタイル指定は毎回貼る。** 同じチャットの中でも、忘れられます。
3. **1枚目が決まったら、それを添付して「この絵柄に合わせて」と言う。** シリーズの統一感はこれで出ます。
4. **直すときは足さず、減らす。** 「情報を減らして」「要素を2つ消して」「線を細く」。AIっぽさは、たいてい“描き込みすぎ”から来ます。
5. 生成後、画像に文字が紛れ込んでいないか必ず確認する（見切れた文字が一番"AI感"を出します）。

## 5. LP実装側でまだ埋まっていないもの

以下は `src/app/lp/page.tsx` 冒頭の `LP_CONFIG` にまとめてあります。確定したら書き換えてください。

- 運営団体の正式名称・所在地・問い合わせ先
- 料金（現在は「準備中」表示）
- CTAのリンク先（現在は `/signup` と `/post`）
- プライバシーポリシー・利用規約のURL
- OGP画像を正しく配信するための `metadataBase`（`src/app/layout.tsx`。公開ドメインが決まったら設定）
- LPを `/` にするかどうか（現在は `/lp`。`/` はアプリのダッシュボード）
